# Elden Ring: Spirit Ashes - Issue & Feedback Tracker

Welcome! This repository is dedicated to bug reports and feature suggestions for the **Elden Ring: Spirit Ashes** Minecraft mod.

### How to Report a Bug
1. Check the [Existing Issues]https://github.com/Eld3lgas/Elden-Ring-Spirit-Ashes-Mod-Issues-Feedback/issues) to make sure your bug hasn't already been reported.
2. Click **New Issue**.
3. Include your Minecraft version, Modloader version, and relevant crash logs or screenshots!

### How to Give Feedback or Suggest a Feature
1. Check the [Existing Issues](https://github.com/Eld3lgas/elden_ring_spirit_ashes_mod_issues_feedback/issues) to make sure your bug hasn't already been reported.
2. Click **New Issue**.
3. Include your Minecraft version, Modloader version, and relevant crash logs or screenshots!
